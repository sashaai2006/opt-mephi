# ЛР №1. План раскроя листового материала

Линейная оптимизация плана раскроя: 4 типа листов (цена, ограниченный запас) и 5 позиций деталей (спрос). Минимизируется стоимость израсходованных листов при покрытии спроса. Вариант 10, seed генерации данных — 10217.

## Установка

Из корня репозитория:

```bash
uv sync
```

Зависимости: `numpy`, `scipy` (решатель HiGHS), `pandas`, `matplotlib`, `tabulate` — уже указаны в `pyproject.toml`.

## Запуск

Один проход: генерация данных (если отсутствуют) → решение базовой задачи и сценариев → проверка NumPy → отчёт, графики, CSV:

```bash
uv run python -m labs.lab1 all
```

Только перегенерировать исходные данные (seed фиксирован, результат воспроизводим):

```bash
uv run python -m labs.lab1 generate
```

## Пример вывода

```
base objective: 28464.55
{'scenario': 'base', 'status': 'optimal', 'objective': 28464.55, 'nit': 9, 'verify_ok': True, ...}
{'scenario': 'deficit', 'status': 'optimal', 'objective': 28479.8, 'nit': 9, 'verify_ok': True, ...}
{'scenario': 'stress', 'status': 'optimal', 'objective': 31125.77, 'nit': 9, 'verify_ok': True, ...}
report: labs/lab1/output/report.md, plots and CSV in labs/lab1/output
```

Оптимум базового сценария: **z\* = 28464.55 руб.** Сценарии: `base`, `deficit` (запас самого используемого типа листов −20%), `stress` (то же + спрос двух позиций +20%).

## Результаты (`output/`)

| Файл | Содержимое |
|---|---|
| `report.md` | Отчёт: постановка, модель, решение, проверка, теневые цены, сценарии, вывод |
| `solution_base.csv` | Ненулевые паттерны базового решения (pattern_id, sheet_id, sheets_used) |
| `scenarios.csv` | Статус, цель, число итераций, результат проверки по каждому сценарию |
| `solver_log.txt` | Лог солвера по сценариям |
| `cost_by_scenario.png`, `sheets_by_scenario.png` | Графики цели и расхода листов |

## Исходные данные (`data/`)

Генерируются `datagen.py` (seed 10217): `sheets.csv` (типы листов: размеры, цена, запас), `items.csv` (детали: размеры, спрос), `patterns.csv` (допустимые паттерны раскроя — полосовая раскладка вдоль длины, не более 8 деталей и 3 видов на лист).

## Структура кода

| Модуль | Назначение |
|---|---|
| `datagen.py` | Генерация данных в CSV по seed |
| `data.py` | Загрузка CSV |
| `model.py` | Построение матриц и вызов `scipy.optimize.linprog` (HiGHS) |
| `verify.py` | Независимая проверка допустимости и цели средствами NumPy (допуск 1e-7) |
| `scenarios.py` | Сценарии и теневые цены |
| `report.py` | Отчёт и графики |
| `__main__.py` | CLI: `generate`, `all` |
