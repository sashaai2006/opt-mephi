# ЛР №2. Транспортная задача с дефицитом и штрафами (вариант 10)

Сетевая ЛП-модель снабжения: 4 склада → 6 магазинов по маршрутам с пропускными способностями. Суммарного запаса не хватает до спроса, поэтому неудовлетворённый спрос явно моделируется переменными дефицита со штрафами. Вариант 10, seed генерации данных — 10217.

## Установка

Из корня репозитория:

```bash
uv sync
```

Зависимости: `numpy`, `scipy` (решатель HiGHS), `pandas`, `matplotlib`, `networkx`, `tabulate` — указаны в `pyproject.toml`.

## Запуск

Один проход: генерация данных (если отсутствуют) → решение базовой задачи и сценариев → независимая проверка NumPy → отчёт, граф сети, CSV:

```bash
uv run python -m labs.lab2 all
```

Только перегенерировать исходные данные (seed фиксирован, результат воспроизводим):

```bash
uv run python -m labs.lab2 generate
```

Оптимум базового сценария: **z\* = 3101.94 руб.** Сценарии: `base`, `failure` (отказ самой загруженной дуги), `deficit` (запас крупнейшего склада −20%), `stress` (спрос всех магазинов +20%).

## Результаты (`output/`)

| Файл | Содержимое |
|---|---|
| `report.md` | Отчёт: постановка, ЛП-модель, решение, проверка, узкие места, сценарии, сравнение с жадной эвристикой, вывод |
| `solution_base.csv` | Ненулевые потоки по маршрутам и дефициты магазинов |
| `scenarios.csv` | Статус, цель, итерации, результат проверки по сценариям |
| `solver_log.txt` | Лог солвера по сценариям |
| `network_flow.png` | Схема сети: поток/пропускная способность, насыщенные дуги красным |
| `cost_by_scenario.png` | Целевая функция по сценариям |

## Исходные данные (`data/`)

Генерируются `datagen.py` (seed 10217): `warehouses.csv` (запасы), `shops.csv` (спрос и штрафы за дефицит), `routes.csv` (тарифы и пропускные способности 24 маршрутов).

## Структура кода

| Модуль | Назначение |
|---|---|
| `datagen.py` | Генерация данных в CSV по seed |
| `data.py` | Загрузка CSV |
| `model.py` | Построение ЛП и вызов `scipy.optimize.linprog` (HiGHS) |
| `verify.py` | Независимая проверка балансов в вершинах, границ на дугах и цели (NumPy, допуск 1e-7) |
| `scenarios.py` | Сценарии, теневые цены, узкие места |
| `greedy.py` | Жадная эвристика «сначала самые дешёвые маршруты» |
| `report.py` | Отчёт и графы |
| `__main__.py` | CLI: `generate`, `all` |
