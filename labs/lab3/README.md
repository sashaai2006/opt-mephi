# ЛР №3. MILP: выбор ассортимента магазина (вариант 10)

Смешанно-целочисленная модель формирования полочного ассортимента: 20 SKU в 6 категориях, бинарные решения «SKU на полке», связки big-M, LP-релаксация и интегральный зазор, масштабный эксперимент и сравнение с жадной эвристикой. Вариант 10, seed генерации данных — 10217.

## Установка

Из корня репозитория:

```bash
uv sync
```

Зависимости: `numpy`, `scipy` (HiGHS: `linprog`/`milp`), `pandas`, `matplotlib`, `tabulate` — указаны в `pyproject.toml`.

## Запуск

Один проход: генерация данных (если отсутствуют) → MILP и LP-релаксация → сценарии → масштабный эксперимент (10/20/40 SKU) → тест с большим big-M → отчёт и графики:

```bash
uv run python -m labs.lab3 all
```

Только перегенерировать исходные данные (seed фиксирован, результат воспроизводим):

```bash
uv run python -m labs.lab3 generate
```

| Файл | Содержимое |

## Исходные данные (`data/`)

Генерируются `datagen.py` (seed 10217): `skus.csv` (20 SKU: категория, спрос, минимальная выкладка, полочная длина единицы, максимальный запас), `categories.csv` (спрос и минимум SKU по 6 категориям), `shelf.csv` (бюджет полки, м).

## Структура кода

| Модуль | Назначение |
|---|---|
| `datagen.py` | Генерация данных в CSV по seed |
| `data.py` | Загрузка CSV |
| `model.py` | Построение MILP/LP и вызов `scipy.optimize.milp` (HiGHS, ветви и границы) |
| `verify.py` | Независимая проверка: бинарность, связки big-M, покрытие, бюджет, пересчёт цели (NumPy, допуск 1e-4) |
| `scenarios.py` | Сценарии, генерация экземпляров масштаба 10/20/40, зазор |
| `greedy.py` | Жадная эвристика «минимальная выкладка первой» |
| `report.py` | Отчёт и графики |
| `__main__.py` | CLI: `generate`, `all` |
