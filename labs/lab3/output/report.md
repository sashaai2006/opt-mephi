## 2. Формальная MILP-модель

- Множества: SKU $s \in S$ (|S| = 20), категории $c \in C$ (|C| = 6), $S_c$ — SKU категории $c$.
- Параметры: $m_s$ — минимальная выкладка (шт.), $U_s$ — максимум запаса SKU на полке (шт.), $a_s$ — полочная длина единицы (м), $D_c$ — спрос категории (шт./нед), $n_c$ — минимум SKU в категории, $B$ — бюджет полки (м).
- Переменные: $y_s \in \{0,1\}$ — SKU выставлен на полку; $x_s \ge 0$ (непрерывная) — выставленный запас (шт.).
- Цель: $\min \sum_s y_s$ — минимум полочных позиций.
- Ограничения:
  1. связка big-M: $x_s \le M_s y_s$, где $M_s = U_s$ — разумная константа: больше $U_s$ хранить бессмысленно;
  2. минимальная выкладка: $x_s \ge m_s y_s$ (выставленный SKU нельзя класть меньше минимума);
  3. покрытие спроса по категориям: $\sum_{s \in S_c} x_s \ge D_c$;
  4. ассортиментное разнообразие: $\sum_{s \in S_c} y_s \ge n_c$;
  5. бюджет полки: $\sum_s a_s x_s \le B$.

**Допущения:** запас любого SKU не ограничен сверх $U_s$; спрос категории взаимозаменяем между SKU категории (классическое допущение ассортиментного планирования); полочная длина линейна по числу единиц.

## 3. Реализация и статус

Модель собрана матрицами NumPy и решена через `scipy.optimize.milp` (HiGHS, ветви и границы, presolve включён, требование зазора 1e-9). LP-релаксация — та же модель без целочисленности. Статус базового решения: **0 — оптимально**. Лог солвера: output/solver_log.txt.

## 4. MILP vs LP-релаксация

- MILP: $z^{*} = 13$ позиций; время 0.0070 с.
- LP-релаксация: $z_{LP} = 12.06$; время 0.0006 с.
- интегральный зазор: **7.3%** от оптимума MILP.

Где «ломается» непрерывное решение: релаксация ставит дробные $y_s$ — например $y_{SKU01} = 0.158$, $y_{SKU04} = 0.842$, $y_{SKU05} = 0.143$, $y_{SKU06} = 0.857$, $y_{SKU08} = 0.056$ …. Физически «пол-SKU на полке» невозможно: округление дробных $y$ вниз разрушает покрытие спроса, вверх — даёт лишние позиции и место; кроме того, набор LP отличается от MILP-набора, то есть оптимальный ассортимент не восстанавливается округлением.

## 5. Независимая проверка (NumPy)

- x >= 0: OK
- 0 <= y <= 1: OK
- целочисленность y (бинарность): OK
- связки big-M x <= U*y: OK
- мин. выкладка x >= m*y: OK
- покрытие спроса всех категорий: OK
- мин. число SKU по категориям: OK
- бюджет полки 28.36 <= 31.60 м: OK
- пересчёт цели 13.00 == solver 13.00: OK
- итог: **допустимо**

## 8. Жадная эвристика

Эвристика: в каждой категории SKU перебираются по возрастанию минимальной выкладки и берутся, пока не достигнуты покрытие спроса и минимум позиций.

- жадная эвристика: 17 позиций, время 0.44 мс, допустимость по полке: да
- MILP-оптимум: 13 позиций
- зазор эвристики: **30.8%** к оптимуму

## 9. Выбор big-M и его нарушение

Разумная константа $M_s = U_s$: она точно отсекает запас несуществующих позиций и не создаёт численных проблем. Проверка с $M = 10^6$ для всех связок:

- статус солвера: optimal, $z = 12$
- независимая проверка связок big-M: **FAIL**
- при огромном $M$ допуск солвера, умноженный на $10^6$, формально разрешает запас у невыставленного SKU: солвер рапортует о «оптимуме» с меньшим числом позиций, но решение недопустимо. Вывод: $M$ берут максимально тесным (здесь $M_s = U_s$).

## 10. Вывод

Оптимальный ассортимент — **13 полочных позиций** (SKU03, SKU04, SKU06, SKU07, SKU08, SKU09, SKU11, SKU12, SKU14, SKU16, SKU17, SKU18, SKU20), покрывающих спрос всех категорий в бюджете 31.6 м полки. LP-релаксация даёт оптимистичную оценку 12.06 (зазор 7.3%); дробные значения $y_s$ показывают, где дискретность качественно меняет решение. Жадная эвристика проигрывает оптимуму; большие big-M разрушают даже допустимость решения.

**Можно ли реализовать на практике?** Модель учитывает главные ограничения полки (место, минимальная выкладка, разнообразие), но не учитывает взаимное влияние SKU на продажи (каннибализацию), несколько полок/уровней, промо-размещение и нелинейность спроса от запаса — для них нужны более богатые модели (см. литературу по ассортиментному планированию).
