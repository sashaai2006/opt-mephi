# opt-mephi

Лабораторные работы по курсу линейного и смешанно-целочисленного программирования (МИФИ, группа Б24-527, вариант 10). Каждая лаборатория — самодостаточный Python-пакет: генерация данных по фиксированному seed, построение модели, решение в HiGHS (SciPy), независимая проверка решения, сценарный анализ, отчёт и графики.

## Лабораторные

| Папка | Тема | Модель | Решатель |
|---|---|---|---|
| `labs/lab1` | План раскроя листового материала | ЛП (паттерны раскроя, покрытие спроса, запасы листов) | `scipy.optimize.linprog` (HiGHS) |
| `labs/lab2` | Транспортная задача с дефицитом и штрафами | ЛП (потоки с пропускными способностями, переменные дефицита) + жадная эвристика | `scipy.optimize.linprog` (HiGHS) |
| `labs/lab3` | Выбор полочного ассортимента магазина | MILP (бинарные решения, big-M) и LP-релаксация | `scipy.optimize.milp` (HiGHS) |

Исходные данные всех лаб генерируются по seed **10217**, результаты полностью воспроизводимы.

## Запуск

Требуется [uv](https://docs.astral.sh/uv/). Из корня репозитория:

```bash
uv sync
uv run python -m labs.lab1 all
uv run python -m labs.lab2 all
uv run python -m labs.lab3 all
```

Команда `all` выполняет полный цикл: генерация данных (если отсутствуют) → решение базовой задачи и сценариев → независимая проверка (NumPy) → отчёт, графики, CSV в `labs/lab*/output/`. Перегенерировать только данные: `uv run python -m labs.labN generate`.

В каждой папке лаборатории:

- `ЛР*_МулярАлександрБ24-527.pdf` — готовый отчёт к сдаче;
- `README.md` — постановка, модель и описание запуска;
- `data/` — исходные данные (CSV), `output/` — результаты и артефакты прогона.

Зависимости: `numpy`, `scipy`, `pandas`, `matplotlib`, `networkx`, `tabulate` (см. `pyproject.toml`).
